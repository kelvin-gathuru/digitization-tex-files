1 MODULE OVERVIEW

When a dataset contains three or more variables and we want to see how they relate simultaneously, standard two-dimensional plots become insufficient. This module introduces practical techniques for visualising multidimensional data in a single view, using colour, shape, size, faceting, and layered geometric objects (geoms). We also examine why statistical software — particularly ggplot2 — is dramatically more capable than spreadsheets for producing these complex visuals clearly and reproducibly.

  1. Describe the main techniques for visualising data with three or more dimensions (aesthetics and facets).

  2. Explain the advantages of statistical software over spreadsheets for creating complex, multidimensional visuals.

  3. Create layered plots that combine multiple aesthetic mappings and faceting to communicate multivariate patterns.

  4. Evaluate whether a multidimensional visualisation communicates its insights effectively or obscures them.

2 BEYOND TWO DIMENSIONS

2.1 1.1 The Dimensionality Problem

A standard scatter plot represents two variables: one on the \(x\)-axis and one on the \(y\)-axis. But most real analytical questions involve more than two variables. How does the relationship between child age and height-for-age vary by sex? Is the effect of household wealth on vaccination coverage different in rural vs. urban areas? How do three or more variables jointly explain an outcome?

Statistical graphics solve this problem by mapping additional variables to visual aesthetics beyond \(x\) and \(y\) position: colour, shape, size, transparency, and line type. Additionally, faceting — creating separate small panels for each level of a variable — allows an entire relationship to be replicated across subgroups.

2.2 1.2 Aesthetic Mappings in ggplot2

In ggplot2, aesthetic mappings connect data variables to visual properties:

Aesthetic

Variable Type

Notes

x, y

Any

Position on axes; the primary mappings.

colour

Categorical or continuous

Hue for categories; colour gradient for continuous. Use colour-blind-safe palettes.

fill

Categorical or continuous

Interior fill for bars, boxes, areas.

shape

Categorical (\(\leq 6\) levels)

Different point shapes per category. Avoid for continuous variables.

size

Continuous

Point or line width; effective for a third continuous variable.

alpha

Continuous

Transparency; useful for overplotting in dense scatter plots.

linetype

Categorical

Solid, dashed, dotted lines for different categories.

2.3 1.3 Faceting

Faceting creates a grid of panels, each showing a subset of the data defined by one or more categorical variables. This is often more readable than mapping a third variable to colour when there are many categories.

Listing 0.1: Multidimensional visualisation with ggplot2 
library(ggplot2)
library(dplyr)

# EXAMPLE 1: Three variables using colour and size
# x = household wealth score, y = HAZ, colour = mother's education,
# size = number of children in household
ggplot(mics_u5, aes(x = hh_wealth, y = haz,
                    colour = mother_educ, size = n_children)) +
  geom_point(alpha = 0.4) +
  scale_colour_viridis_d(name = "Mother's Education") +
  labs(title = "Wealth, Maternal Education, and Child Nutritional Status",
       x = "Household Wealth Score", y = "HAZ Score",
       size = "No. of Children",
       caption = "Source: MICS Kenya 2014")

# EXAMPLE 2: Faceted plot - relationship by region and urban/rural
ggplot(mics_u5, aes(x = child_age_months, y = haz)) +
  geom_point(alpha = 0.2, colour = "#037b90") +
  geom_smooth(method = "loess", colour = "#ff7f50") +
  facet_grid(region ~ urban_rural) +
  labs(title = "Age-HAZ Relationship by Region and Residence Type",
       x = "Child Age (months)", y = "HAZ Score")

# EXAMPLE 3: Layered geoms (points + boxplot + jitter)
ggplot(mics_u5, aes(x = mother_educ, y = haz, fill = mother_educ)) +
  geom_violin(alpha = 0.4) +
  geom_jitter(width = 0.1, alpha = 0.1, colour = "#2B7A78") +
  stat_summary(fun = median, geom = "point", size = 3, colour = "#ff7f50") +
  coord_flip() +
  labs(title = "Distribution of HAZ by Mother's Education Level")

3 SPREADSHEETS VS. STATISTICAL SOFTWARE FOR COMPLEX VISUALISATION

3.1 2.1 Why Spreadsheets Struggle with Multidimensional Visuals

Excel can produce a chart with colour mapped to a category, but this requires manual steps that are:

  • Not reproducible: The same chart cannot be recreated automatically from the data.

  • Fragile: Changing the data requires manually recreating the chart.

  • Limited: Excel cannot natively produce faceted plots, violin plots, or properly layered geoms.

  • Error-prone: Colour assignments can shift if data is sorted differently.

In R, a multidimensional chart is produced by a single, 10-line code block that automatically updates if the data changes, is reproducible by anyone who runs the code, and handles thousands of data points gracefully.

3.2 2.2 Evaluating Multidimensional Visual Effectiveness

A multidimensional visualisation is effective if:

  • The reader can immediately identify what each visual channel (colour, size, facet) represents.

  • The insight claimed in the caption is clearly visible in the chart without requiring mental calculation.

  • No aesthetic is used for a variable that would be better represented by a different channel.

  • The chart does not overload the reader with too many simultaneous mappings (practical limit: 3–4 variables per chart).

5 KEY CONCEPTS AND TERMINOLOGY

Term

Definition

Aesthetic Mapping

A connection between a data variable and a visual property (position, colour, shape, size, alpha) in a ggplot2 plot.

Faceting

Creating a grid of small panels, each showing a subset of data defined by one or more categorical variables.

Geom

A geometric object used to represent data in ggplot2 (e.g., geom_point, geom_boxplot, geom_violin).

Layered Plot

A ggplot2 plot combining multiple geometric objects to show the same data from different perspectives simultaneously.

Overplotting

A visualisation problem where too many data points overlap, obscuring the density of the distribution. Addressed with alpha transparency or jittering.

Grammar of Graphics

A framework (Wilkinson, 2005; Wickham, 2010) for constructing statistical graphics by specifying data, aesthetic mappings, geometric objects, and scales.

  • Multidimensional visualisation maps additional variables to visual channels beyond \(x\)/\(y\) position: colour, shape, size, transparency, and faceting.

  • Statistical software (ggplot2) dramatically outperforms spreadsheets for multidimensional visuals: reproducible, flexible, extensible, and scalable to large datasets.

  • Effective multidimensional charts are legible (3–4 variables maximum), clearly labelled, and show patterns not visible in simpler views.

  • Faceting is often more readable than colour for categorical variables with more than 4–5 levels.

  • A good visualisation does not just display data — it reveals a story that is difficult to see in numbers alone.
