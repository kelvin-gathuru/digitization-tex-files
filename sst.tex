\section{Artificial Neural Networks}
\subsection{Definition and Characteristics}
Neural networks are designed using mathematical equations to mimic the biological neurons in the body system. Each neuron is designed to pick a signal, transmit to interpretation center, and send response signal, either to stimulate or suppress the original source of stimulus.
Artificial Neural Networks (ANN) are computational models created using mathematical equations, that mimic biological neurons.These ANN are characterized by:
\begin{itemize}
\item Input Layer: Receives data.
\item Hidden Layers: Process information.
\item Output Layer: Produces results.
\end{itemize}

\subsection{Practical Worked Example with Python}
\textbf{Bulding a simple XOR Problem ANN}
The XOR function is a classic classification problem solved using a neural network. A simple ANN with one hidden layer can learn to classify XOR inputs.
\begin{verbatim}
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

# Define model
model = Sequential([
    Dense(2, activation='relu', input_shape=(2,)),
    Dense(1, activation='sigmoid')
])

# Compile model
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

# Example input
import numpy as np
X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([0, 1, 1, 0])

# Train model
model.fit(X, y, epochs=100, verbose=0)

# Predict
print(model.predict(X))
\end{verbatim}
\end{example}

\section{Neural Network Applications in Simulation}
\subsection{Definition and Characteristics}
An artificial Neural Network ANN is a framework of interconnected artificial neurons forming layer. Each neuron receives an input signal, applies weights and passes the resut through activation function. The output signal is adjusted using weights through backpropagation algorithms and gradient descent. Once the error is eliminated, the ANN will have correctly completed the task of image recognition, speech processing, music composition, financial forecasting, or medical diagnosis.
Artificial Neural Networks (ANNs) are computational models that mimic biological neurons. They consist of:
\begin{itemize}
    \item Input Layer: Receives data.
    \item Hidden Layers: Process information.
    \item Output Layer: Produces results.
\end{itemize}

\section{Training and Optimizing Neural Models}
Training of neural network is the process which involves adjusting of weights and biases (parameters), so as to predict accurately using provided historical data sets. The data is subdivided into three, namely:
\begin{enumerate}
\item A set if input features $X$, which consist of data to be used to make prediction
\item A set of output target label, $Y$, which is a set of correct values of data targetted
\item A set of training, validation and test set explained below.
\begin{itemize}
\item Training data is a set of data used to adjust the model parameters. This process is called training
\item This is a st of validation data, which refers to the process of moderating the fitting of the model to the data
\item Test set is the data used to check the performance of the model whether prediction is accurate
\end{itemize}
\end{enumerate}
\subsection{Optimization}
Optimization problem involves the evaluation of an objective function, which could be maximization or minimization problem, subject to provided constraints. An optimization problem is formulated with the following components; Objective function, Constraints, and declaration of feasibility space or region. Neural networks are widely used in optimization problems due to their ability to learn complex patterns, approximate functions, and improve decision-making processes. Their applications span various fields, including engineering;(structural design, control systems, and smart grid energy mix), finance (stock price prediction, portfolio management, fraud detection), healthcare (diagnosis, cancer progression, drug discovery, patient management), and artificial intelligence (reinforcement learning, robotics, hyperparameter tunnng, and neural architecture search).
\subsection{Optimization Techniques}
Neural networks require optimization for better performance. Some of optimization techniques used include:
\begin{itemize}
    \item \textbf{Gradient Descent}. Gradient Descent is a process where the approach to the maximum or minimum poit of a function is based on the gradient (steepness or gentleness) of the slope. The step size towards the optimal point is based on the magnitude of the gradient function. This process is involved in the adjustment of weights to minimize error.
    \item \textbf{Regularization}. Regularization in neural network optimization technique used to prevent overfitting and improve the model’s ability to generalize to unseen data. Overfitting occurs when a neural network learns the training data too well, including noise, making it perform poorly on new data, or there are unforeseen small changes.
    \item \textbf{Hyperparameter Tuning}. These are the settings adjusted in the neural network model before training, to determine the rate of training, batch size of data used, and the level of accuracy of prediction. Hyperparameter tunning depends on the complexity of the model, accuracy of the expected results and the desired training time.
\end{itemize}
\begin{example}
Using dropout layers and batch normalization improves model accuracy.
\bf{Python Example: Optimizing a Neural Network}
\begin{verbatim}
from tensorflow.keras.layers import Dropout, BatchNormalization

# Define optimized model
model = Sequential([
    Dense(64, activation='relu', input_shape=(10,)),
    BatchNormalization(),
    Dropout(0.2),
    Dense(1)
])

# Compile and train
model.compile(optimizer='adam', loss='mse')
model.fit(X, y, epochs=50, verbose=0)
\end{verbatim}
\end{example}

import tensorflow as tf
from tensorflow import keras
import numpy as np
import matplotlib.pyplot as plt

# Load MNIST dataset
mnist = keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()

# Normalize pixel values
x_train, x_test = x_train / 255.0, x_test / 255.0

# Build Neural Network Model
model = keras.Sequential([
    keras.layers.Flatten(input_shape=(28, 28)),  # Input layer
    keras.layers.Dense(128, activation='relu'),  # Hidden layer
    keras.layers.Dropout(0.2),  # Dropout to prevent overfitting
    keras.layers.Dense(10, activation='softmax')  # Output layer
])

# Compile the model
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# Train the model
model.fit(x_train, y_train, epochs=5)

# Evaluate performance
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=2)
print(f"Test Accuracy: {test_acc:.2f}")

# Predict a digit
prediction = model.predict(np.expand_dims(x_test[0], axis=0))
plt.imshow(x_test[0], cmap='gray')
plt.show()
print(f"Predicted Digit: {np.argmax(prediction)}")
\end{verbatim}
