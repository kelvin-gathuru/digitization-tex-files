Cognitive Levels in the Revised Bloom’s Taxonomy

1 Introduction

The Revised Bloom’s Taxonomy, developed by Lorin Anderson and David Krathwohl (2001), updates the original taxonomy by Benjamin Bloom.

It organizes cognitive learning into six hierarchical levels, moving from lower-order to higher-order thinking skills. These levels guide curriculum design, instruction, and assessment—especially in competency-based education and training (CBET).

2 Cognitive Levels

2.1 1. Remember (Knowledge Recall)

Definition:

Retrieving relevant knowledge from long-term memory.

Key Focus:

Facts, terms, basic concepts.

Examples of Learning Behaviors:

  • Recalling definitions

  • Listing components

  • Identifying concepts

Common Verbs for Learning Outcomes:

  • Define

  • List

  • Recall

  • Identify

  • Name

  • State

  • Recognize

  • Label

  • Outline

Example Outcome:

Define occupational standards within a CBET framework.

2.2 2. Understand (Comprehension)

Definition:

Constructing meaning from instructional messages.

Key Focus:

Explaining ideas or concepts.

Examples of Learning Behaviors:

  • Summarizing information

  • Interpreting data

  • Explaining relationships

Common Verbs:

  • Explain

  • Describe

  • Discuss

  • Summarize

  • Interpret

  • Classify

  • Compare

  • Paraphrase

  • Illustrate

Example Outcome:

Explain the components of occupational standards.

2.3 3. Apply (Application)

Definition:

Carrying out or using a procedure in a given situation.

Key Focus:

Using knowledge in practical contexts.

Examples of Learning Behaviors:

  • Implementing procedures

  • Demonstrating skills

  • Solving problems

Common Verbs:

  • Apply

  • Demonstrate

  • Use

  • Implement

  • Calculate

  • Solve

  • Perform

  • Execute

  • Construct

Example Outcome:

Apply competency elements to develop performance criteria.

2.4 4. Analyze (Analysis)

Definition:

Breaking material into parts and determining relationships.

Key Focus:

Examining structure, patterns, and connections.

Examples of Learning Behaviors:

  • Differentiating components

  • Organizing ideas

  • Investigating causes

Common Verbs:

  • Analyze

  • Differentiate

  • Compare

  • Contrast

  • Examine

  • Organize

  • Deconstruct

  • Investigate

  • Categorize

Example Outcome:

Analyze stakeholder roles in competency identification.

2.5 5. Evaluate (Evaluation)

Definition:

Making judgments based on criteria and standards.

Key Focus:

Critiquing, justifying, and defending decisions.

Examples of Learning Behaviors:

  • Assessing effectiveness

  • Justifying recommendations

  • Critiquing processes

Common Verbs:

  • Evaluate

  • Assess

  • Critique

  • Justify

  • Recommend

  • Appraise

  • Defend

  • Validate

  • Judge

Example Outcome:

Evaluate the effectiveness of stakeholder engagement strategies.

2.6 6. Create (Synthesis)

Definition:

Putting elements together to form a new structure or pattern.

Key Focus:

Designing, producing, developing new ideas.

Examples of Learning Behaviors:

  • Designing frameworks

  • Developing plans

  • Producing original work

Common Verbs:

  • Create

  • Design

  • Develop

  • Formulate

  • Construct

  • Propose

  • Generate

  • Compose

  • Plan

Example Outcome:

Design a competency framework aligned with industry needs.

3 Key Characteristics of the Revised Taxonomy

  • Uses action verbs instead of nouns (e.g., Remember instead of Knowledge).

  • Emphasizes measurable learning outcomes.

  • Supports alignment between learning outcomes, instructional strategies, and assessment.

  • Encourages progression from lower-order to higher-order thinking skills.

4 Guidelines for Writing Learning Outcomes

  1. Start with an action verb aligned to the intended cognitive level.

  2. Specify the content (what learners will know or do).

  3. Ensure measurability (avoid vague verbs like “understand”).

  4. Align with assessment methods.

  5. Match the competency level required in the occupational context.

Formula:

By the end of the module, learners will be able to + action verb + content + (context/conditions, if needed).

Example (CBET Context):

By the end of the course, trainees will be able to analyze industry needs and develop competency standards aligned with occupational requirements.

5 Conclusion

The Revised Bloom’s Taxonomy provides a structured framework for designing learning outcomes that move learners from simple recall to creative problem-solving. Selecting appropriate action verbs ensures clarity, measurability, and alignment with competency-based education and training objectives.
