\section{Core Techniques and Applications}
% ============================================================

The techniques covered in this module are applied across all tiers of security operations:
\begin{itemize}
    \item \textbf{Tier 1 Analysts:} Use these techniques for initial alert triage.
    \item \textbf{Tier 2 Analysts:} Apply them for incident investigation.
    \item \textbf{Tier 3 Analysts:} Employ them for advanced threat hunting and detection engineering.
\end{itemize}

Refer to the worked examples, the supplementary video, and the diagram in this module for demonstrations applied to realistic security datasets. The mastery exercise below tests your understanding before you attempt the end-of-module assessment.

\begin{example}
\textbf{Exploratory Security Data Analysis --- Practical Application}

\textit{Context:} A SOC analyst is applying exploratory security data analysis techniques to a suspected security incident in an enterprise environment.

\begin{enumerate}
    \item \textbf{Step 1:} Collect and validate the relevant data sources for this analysis.
    \item \textbf{Step 2:} Apply the primary technique from this module's reading material.
    \item \textbf{Step 3:} Interpret the output and formulate a security hypothesis.
    \item \textbf{Step 4:} Cross-reference findings with threat intelligence and asset data.
\end{enumerate}

\textbf{Outcome:} Evidence-based recommendation for escalation or dismissal.
\end{example}
