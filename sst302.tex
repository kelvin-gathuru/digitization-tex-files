\section{Introduction to MCMC Techniques}
MCMC is a class of algorithms used to sample from complex probability distributions. It constructs a Markov chain whose equilibrium distribution matches the target distribution, allowing efficient sampling in high-dimensional spaces.

\subsection{ Types of common statistical Distributions}
There are various MCMC techniques widely used These include:
\begin{itemize}
    \item Bayesian statistics for posterior distribution estimation.
    \item Machine learning for probabilistic modeling.
    \item Finance for risk assessment.
    \item Genetics for evolutionary analysis.
\end{itemize}

\section{ Adaptive MCMC Methods }
Adaptive MCMC modifies proposal distributions dynamically to improve sampling efficiency.
\textbf{Examples of Adaptive MCMC}
\begin{itemize}
    \item Adaptive Metropolis Algorithm – Adjusts proposal covariance matrix.
    \item Delayed Rejection Adaptive Metropolis (DRAM) – Enhances acceptance rates.
    \item Adaptive Gibbs Sampling – Adjusts transition probabilities
\end{itemize}

\textbf{Python Example: Adaptive Metropolis Algorithm}
\begin{verbatim}
import numpy as np

def metropolis_hastings(target_dist, proposal_std, steps):
    samples = []
    x = np.random.rand()
    for _ in range(steps):
        x_new = x + np.random.normal(0, proposal_std)
        accept_prob = min(1, target_dist(x_new) / target_dist(x))
        if np.random.rand() < accept_prob:
            x = x_new
        samples.append(x)
    return samples

target = lambda x: np.exp(-x**2)  # Example target distribution
samples = metropolis_hastings(target, 0.5, 1000)
\end{verbatim}

\textbf{Python Example: Gibbs Sampling}
\begin{verbatim}
import numpy as np

def gibbs_sampling(steps):
    x, y = 0, 0
    samples = []
    for _ in range(steps):
        x = np.random.normal(y, 1)
        y = np.random.normal(x, 1)
        samples.append((x, y))
    return samples

samples = gibbs_sampling(1000)
\end{verbatim}

\textbf{Python Example: Gibbs Sampling}
\begin{verbatim}
import numpy as np

def hamiltonian_monte_carlo(target, grad_target, steps, step_size):
    x = np.random.rand()
    samples = []
    for _ in range(steps):
        p = np.random.normal(0, 1)
        x_new = x + step_size * p
        accept_prob = min(1, target(x_new) / target(x))
        if np.random.rand() < accept_prob:
            x = x_new
        samples.append(x)
    return samples

target = lambda x: np.exp(-x**2)
grad_target = lambda x: -2*x
samples = hamiltonian_monte_carlo(target, grad_target, 1000, 0.1)
\end{verbatim}
