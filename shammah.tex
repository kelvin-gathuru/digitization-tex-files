\section{ARIMA, VAR, ETS, and Classical Decomposition}
% ============================================================

This section introduces the main forecasting models used in policy simulation. Understanding their structure helps students choose the right model for the type of data they are working with and the policy question they want to answer. These models are widely used because they capture trends, patterns, and dynamic relationships in economic time series.

\subsection{ARIMA Models}

ARIMA stands for Autoregressive Integrated Moving Average. It is one of the most common methods for forecasting time-series data. The model combines past values of the series, differencing to achieve stationarity, and past forecast errors to improve prediction.

\begin{itemize}
    \item \textbf{AR(p):} Uses past values of the series.
    \item \textbf{I(d):} Indicates the number of differencing steps needed to make the series stationary.
    \item \textbf{MA(q):} Uses past forecast errors.
\end{itemize}

An ARIMA model is written as ARIMA(p,d,q). For example, ARIMA(1,1,1) includes one autoregressive term, one differencing step, and one moving average term. ARIMA models are useful when the data show autocorrelation and no strong seasonal pattern.

\subsection{VAR Models}

VAR stands for Vector Autoregression. It is used when two or more time series are related and may influence one another over time. Unlike a univariate model, VAR treats each variable as potentially dependent on both its own past values and the past values of the other variables.

\begin{itemize}
    \item \textbf{k:} The number of variables in the system.
    \item Each variable is explained by its own lagged values and the lagged values of the other variables.
\end{itemize}

VAR models are useful for studying relationships among macroeconomic variables such as inflation, GDP growth, interest rates, and unemployment.

\subsection{ETS Models}

ETS stands for Error, Trend, Seasonal. These models are based on exponential smoothing and are especially effective when a series shows a clear trend or seasonal pattern. ETS models are often preferred when the goal is accurate forecasting rather than structural interpretation.

\begin{itemize}
    \item \textbf{Error:} How the model handles random disturbances.
    \item \textbf{Trend:} Whether the series is rising, falling, or stable over time.
    \item \textbf{Seasonal:} Whether the series repeats in a regular pattern.
\end{itemize}

ETS models may be additive or multiplicative depending on how the components behave in the data.

\subsection{Classical Decomposition}

Classical decomposition separates a time series into three parts:

\begin{itemize}
    \item \textbf{Trend:} The long-term movement in the data.
    \item \textbf{Seasonal:} Regular patterns that repeat over fixed intervals.
    \item \textbf{Irregular:} Random fluctuations that cannot be easily predicted.
\end{itemize}

After identifying the structure of ARIMA, VAR, ETS, and decomposition models, the next step is to evaluate how accurate their forecasts are. A model may fit the historical data well, but that does not guarantee strong predictive performance.

\section{Forecast Evaluation Metrics}
% ============================================================

In this section, we test the forecasting models by checking how close their predictions are to the actual data. The goal is to find out which model gives the most reliable forecasts.

In plain terms:
\begin{itemize}
    \item \textbf{MAE} tells us the average size of the mistakes.
    \item \textbf{RMSE} tells us whether the model makes big mistakes.
    \item \textbf{MAPE} shows the error in percentage terms.
    \item \textbf{MASE} compares the model to a simple benchmark.
    \item \textbf{Diebold--Mariano} helps us decide whether one model is truly better than another.
\end{itemize}

Throughout this section, use the following simple example:
\begin{itemize}
    \item Actual values: 10, 12, 14
    \item Forecast values: 9, 13, 15
\end{itemize}

This gives forecast errors of $1$, $1$, and $1$ in absolute terms.

\subsection{Mean Absolute Error (MAE)}

MAE measures the average size of the forecast errors without considering direction. It is easy to interpret because it is in the same units as the original variable. Lower MAE values indicate better forecast accuracy.

\begin{example}
If the absolute errors are 1, 1, and 1, then:
\[ \mathrm{MAE} = (1 + 1 + 1) / 3 = 1 \]
This means the model is off by 1 unit on average.
\end{example}

\subsection{Root Mean Square Error (RMSE)}

RMSE measures the size of forecast errors but gives greater weight to large mistakes. This makes it useful when big forecasting errors are especially costly. Lower RMSE values indicate better performance.

\begin{example}
If the errors are 1, 1, and 1, then:
\[ \mathrm{RMSE} = \sqrt{(1^{2} + 1^{2} + 1^{2}) / 3} = 1 \]
If one error were 4 instead of 1, RMSE would rise more sharply than MAE.
\end{example}

\subsection{Mean Absolute Percentage Error (MAPE)}

MAPE expresses forecast error as a percentage of the actual value, which makes it easy to explain to non-technical audiences. It is useful when relative error matters more than absolute error. However, it can be misleading when actual values are very small or close to zero.

\begin{example}
For actual value 10 and forecast 9, the percentage error is:
\[ |10 - 9| / 10 = 10\% \]
If the errors are $10\%$, $8.3\%$, and $7.1\%$, MAPE is the average of those percentages.
\end{example}

\subsection{Mean Absolute Scaled Error (MASE)}

MASE compares a model's forecast accuracy against a simple naive benchmark, such as a random walk or lagged forecast. A MASE value below 1 means the model performs better than the benchmark. This makes MASE useful when comparing forecasts across different datasets or series.

\begin{example}
If a model has $\mathrm{MAE} = 1$ and the naive benchmark has $\mathrm{MAE} = 2$, then:
\[ \mathrm{MASE} = 1 / 2 = 0.5 \]
This means the model is twice as good as the naive forecast.
\end{example}

\subsection{Diebold--Mariano Test}

The Diebold--Mariano test compares the predictive accuracy of two competing forecasts. It helps determine whether one model is statistically better than another rather than just appearing better by chance. This is useful when deciding between models such as ARIMA and ETS, or ARIMA and VAR.

\begin{example}
Suppose Model A has smaller forecast errors than Model B. The Diebold--Mariano test checks whether that difference is large enough to be statistically meaningful. If the p-value is small, you can conclude that one model forecasts significantly better than the other.
\end{example}

\section{Estimating Forecasting Models in R}
% ============================================================

After identifying forecasting models and evaluating their accuracy, this section introduces the practical steps involved in fitting ARIMA, VAR, and ETS models to economic data and generating forecasts for policy analysis.

\subsection{Fitting ARIMA Models}

ARIMA models are often estimated using the \texttt{forecast} package in R. Before fitting the model, the data should be arranged as a time-series object. Use \texttt{auto.arima()} to select a suitable model automatically, or specify the ARIMA structure manually if needed.

\begin{example}
If unemployment data show a pattern over time, convert the series into a time-series object and estimate an ARIMA model to forecast future unemployment levels. This demonstrates how past values and past errors are used to predict the next observation.
\end{example}

\subsection{Fitting VAR Models}

VAR models are estimated using the \texttt{vars} package in R. These models are useful when two or more economic variables influence one another over time. Place the variables in a single dataset, choose an appropriate lag length, and then estimate the model.

\begin{example}
Use inflation and interest rate data in a VAR model to study how each variable affects the other over time. This is useful for policy questions where variables move together dynamically.
\end{example}

\subsection{Fitting ETS Models}

ETS models are also estimated using the \texttt{forecast} package in R. These models are especially useful for time series that show trend or seasonal patterns. After fitting the model, generate forecasts and compare them with those from ARIMA or other methods.

\begin{example}
If quarterly sales data rise over time and repeat each year, an ETS model can capture both the trend and seasonality, making it helpful for forecasting data that follow a regular pattern.
\end{example}

\section{Selecting Optimal Models}
% ============================================================

After estimating forecasting models, we need to decide which one performs best. This section explains how to compare models using information criteria, forecast accuracy measures, and forecast failure analysis.

\subsection{AIC and BIC}

AIC and BIC are used to compare models while taking model complexity into account. A lower value usually indicates a better balance between fit and simplicity. These measures are useful when comparing ARIMA, ETS, or VAR models fitted to the same data.

\begin{example}
If Model A has a lower AIC than Model B, then Model A is generally preferred because it fits the data well without being unnecessarily complicated. However, forecast accuracy should still be checked before making a final decision.
\end{example}

\subsection{Accuracy Competitions}

Accuracy competitions compare how well different models forecast unseen data. Students can use measures such as MAE and RMSE to see which model makes the smallest prediction errors. This step is important because the model with the best fit is not always the one with the best forecasts.

\begin{example}
Suppose ARIMA has a lower RMSE than ETS on the test sample. In that case, ARIMA would be preferred for forecasting, even if ETS had a slightly lower AIC. This shows why forecast accuracy matters beyond model fit.
\end{example}

\subsection{Forecast Failure Analysis}

Forecast failure analysis helps students understand when and why a model performs poorly. A model may fail because of structural breaks, sudden shocks, omitted variables, or changes in the pattern of the data. Studying failure is useful because it teaches students not just to pick a model, but also to recognize its limits.

\begin{example}
If a forecasting model works well during stable periods but performs badly during an economic crisis, this suggests the series changed in ways the model could not capture. This shows why models must be interpreted with caution.
\end{example}
