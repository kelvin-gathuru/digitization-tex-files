\section{Introduction}

The Revised Bloom's Taxonomy, developed by Lorin Anderson and David Krathwohl (2001), updates the original taxonomy by Benjamin Bloom.

It organizes cognitive learning into six hierarchical levels, moving from lower-order to higher-order thinking skills. These levels guide curriculum design, instruction, and assessment—especially in competency-based education and training (CBET).

\section{Cognitive Levels}

\subsection{1. Remember (Knowledge Recall)}

\textbf{Definition:}

Retrieving relevant knowledge from long-term memory.

\textbf{Key Focus:}

Facts, terms, basic concepts.

\textbf{Examples of Learning Behaviors:}

\begin{itemize}
    \item Recalling definitions
    \item Listing components
    \item Identifying concepts
\end{itemize}

\textbf{Common Verbs for Learning Outcomes:}

\begin{itemize}
    \item Define
    \item List
    \item Recall
    \item Identify
    \item Name
    \item State
    \item Recognize
    \item Label
    \item Outline
\end{itemize}

\textbf{Example Outcome:}

Define occupational standards within a CBET framework.

\subsection{2. Understand (Comprehension)}

\textbf{Definition:}

Constructing meaning from instructional messages.

\textbf{Key Focus:}

Explaining ideas or concepts.

\textbf{Examples of Learning Behaviors:}

\begin{itemize}
    \item Summarizing information
    \item Interpreting data
    \item Explaining relationships
\end{itemize}

\textbf{Common Verbs:}

\begin{itemize}
    \item Explain
    \item Describe
    \item Discuss
    \item Summarize
    \item Interpret
    \item Classify
    \item Compare
    \item Paraphrase
    \item Illustrate
\end{itemize}

\textbf{Example Outcome:}

Explain the components of occupational standards.

\subsection{3. Apply (Application)}

\textbf{Definition:}

Carrying out or using a procedure in a given situation.

\textbf{Key Focus:}

Using knowledge in practical contexts.

\textbf{Examples of Learning Behaviors:}

\begin{itemize}
    \item Implementing procedures
    \item Demonstrating skills
    \item Solving problems
\end{itemize}

\textbf{Common Verbs:}

\begin{itemize}
    \item Apply
    \item Demonstrate
    \item Use
    \item Implement
    \item Calculate
    \item Solve
    \item Perform
    \item Execute
    \item Construct
\end{itemize}

\textbf{Example Outcome:}

Apply competency elements to develop performance criteria.

\subsection{4. Analyze (Analysis)}

\textbf{Definition:}

Breaking material into parts and determining relationships.

\textbf{Key Focus:}

Examining structure, patterns, and connections.

\textbf{Examples of Learning Behaviors:}

\begin{itemize}
    \item Differentiating components
    \item Organizing ideas
    \item Investigating causes
\end{itemize}

\textbf{Common Verbs:}

\begin{itemize}
    \item Analyze
    \item Differentiate
    \item Compare
    \item Contrast
    \item Examine
    \item Organize
    \item Deconstruct
    \item Investigate
    \item Categorize
\end{itemize}

\textbf{Example Outcome:}

Analyze stakeholder roles in competency identification.

\subsection{5. Evaluate (Evaluation)}

\textbf{Definition:}

Making judgments based on criteria and standards.

\textbf{Key Focus:}

Critiquing, justifying, and defending decisions.

\textbf{Examples of Learning Behaviors:}

\begin{itemize}
    \item Assessing effectiveness
    \item Justifying recommendations
    \item Critiquing processes
\end{itemize}

\textbf{Common Verbs:}

\begin{itemize}
    \item Evaluate
    \item Assess
    \item Critique
    \item Justify
    \item Recommend
    \item Appraise
    \item Defend
    \item Validate
    \item Judge
\end{itemize}

\textbf{Example Outcome:}

Evaluate the effectiveness of stakeholder engagement strategies.

\subsection{6. Create (Synthesis)}

\textbf{Definition:}

Putting elements together to form a new structure or pattern.

\textbf{Key Focus:}

Designing, producing, developing new ideas.

\textbf{Examples of Learning Behaviors:}

\begin{itemize}
    \item Designing frameworks
    \item Developing plans
    \item Producing original work
\end{itemize}

\textbf{Common Verbs:}

\begin{itemize}
    \item Create
    \item Design
    \item Develop
    \item Formulate
    \item Construct
    \item Propose
    \item Generate
    \item Compose
    \item Plan
\end{itemize}

\textbf{Example Outcome:}

Design a competency framework aligned with industry needs.

\section{Key Characteristics of the Revised Taxonomy}

\begin{itemize}
    \item Uses action verbs instead of nouns (e.g., Remember instead of Knowledge).
    \item Emphasizes measurable learning outcomes.
    \item Supports alignment between learning outcomes, instructional strategies, and assessment.
    \item Encourages progression from lower-order to higher-order thinking skills.
\end{itemize}

\section{Guidelines for Writing Learning Outcomes}

\begin{enumerate}
    \item Start with an action verb aligned to the intended cognitive level.
    \item Specify the content (what learners will know or do).
    \item Ensure measurability (avoid vague verbs like ``understand'').
    \item Align with assessment methods.
    \item Match the competency level required in the occupational context.
\end{enumerate}

\textbf{Formula:}

\begin{quote}
By the end of the module, learners will be able to + action verb + content + (context/conditions, if needed).
\end{quote}

\textbf{Example (CBET Context):}

\begin{quote}
By the end of the course, trainees will be able to analyze industry needs and develop competency standards aligned with occupational requirements.
\end{quote}

\section{Conclusion}

The Revised Bloom's Taxonomy provides a structured framework for designing learning outcomes that move learners from simple recall to creative problem-solving. Selecting appropriate action verbs ensures clarity, measurability, and alignment with competency-based education and training objectives.
