\maketitle

The Revised Bloom's Taxonomy (Anderson \& Krathwohl, 2001) provides a structured framework for writing clear, specific, and measurable learning outcomes. It organizes cognitive learning into six hierarchical levels:

\begin{enumerate}
    \item Remember
    \item Understand
    \item Apply
    \item Analyze
    \item Evaluate
    \item Create
\end{enumerate}

To make learning outcomes measurable, they must use observable action verbs and clearly describe what the learner will be able to do at the end of instruction.

\section{Structure of a Measurable Learning Outcome}

A well-written learning outcome typically includes:

\textbf{Condition + Audience + Behavior + Degree (CABD Model)}

\subsection*{Example Structure}

\textit{By the end of the lesson, learners will be able to analyze case studies on occupational standards and identify at least four competency gaps correctly.}

\vspace{0.3cm}

Where:

\begin{itemize}
    \item \textbf{Condition} -- Under what circumstances? (e.g., given a case study)
    \item \textbf{Audience} -- Who? (e.g., learners, trainees)
    \item \textbf{Behavior} -- Observable action (e.g., analyze, design, compare)
    \item \textbf{Degree} -- Level of performance (e.g., with 80\% accuracy)
\end{itemize}

\section{Cognitive Levels with Action Verbs and Examples}

\subsection{Remember (Recall facts and basic concepts)}

\textbf{Action verbs:} define, list, name, identify, recall, state

\textbf{Example Outcomes:}

\begin{itemize}
    \item Define the term occupational standard.
    \item List the components of a competency framework.
    \item Identify five stakeholder groups involved in competency validation.
\end{itemize}

\textbf{Measurable because:} learners must demonstrate recall.

\subsection{Understand (Explain ideas or concepts)}

\textbf{Action verbs:} explain, describe, summarize, classify, discuss, interpret

\textbf{Example Outcomes:}

\begin{itemize}
    \item Explain the relationship between competency elements and performance criteria.
    \item Summarize the process of stakeholder engagement in curriculum design.
    \item Classify different types of competencies in a given occupation.
\end{itemize}

\textbf{Measurable because:} can be assessed through written or oral explanation.

\subsection{Apply (Use information in new situations)}

\textbf{Action verbs:} apply, demonstrate, use, implement, calculate, solve

\textbf{Example Outcomes:}

\begin{itemize}
    \item Apply Bloom's taxonomy to develop learning outcomes for a CBET module.
    \item Demonstrate how to formulate performance criteria from industry standards.
    \item Use a competency template to draft an occupational standard.
\end{itemize}

\textbf{Measurable because:} can be assessed through practical tasks or assignments.

\subsection{Analyze (Draw connections among ideas)}

\textbf{Action verbs:} analyze, differentiate, compare, contrast, examine, organize

\textbf{Example Outcomes:}

\begin{itemize}
    \item Analyze the strengths and weaknesses of different curriculum design models.
    \item Compare competency-based education with traditional education models.
    \item Differentiate between core and functional competencies in a case study.
\end{itemize}

\textbf{Measurable because:} can be assessed through analytical reports or structured discussions.

\subsection{Evaluate (Justify a decision or position)}

\textbf{Action verbs:} evaluate, justify, assess, critique, defend, recommend

\textbf{Example Outcomes:}

\begin{itemize}
    \item Evaluate the effectiveness of a stakeholder engagement plan.
    \item Critique a sample occupational standard using given criteria.
    \item Recommend improvements to a competency framework based on industry feedback.
\end{itemize}

\textbf{Measurable because:} assessed through evidence-based arguments.

\subsection{Create (Produce new or original work)}

\textbf{Action verbs:} design, develop, formulate, construct, create, propose

\textbf{Example Outcomes:}

\begin{itemize}
    \item Design a competency-based assessment tool for a specific occupation.
    \item Develop measurable performance criteria for a selected job role.
    \item Construct a competency framework aligned with industry needs.
\end{itemize}

\textbf{Measurable because:} assessed through production of original work.

\section{Characteristics of Measurable Learning Outcomes}

Effective learning outcomes should be:

\begin{itemize}
    \item \textbf{Specific} -- Clear and focused
    \item \textbf{Observable} -- Can be seen or measured
    \item \textbf{Measurable} -- Includes criteria for success
    \item \textbf{Learner-centered} -- Focus on learner performance
    \item \textbf{Aligned} -- Linked to assessment and instruction
\end{itemize}

\section{Avoid Non-Measurable Verbs}

Avoid vague verbs such as:

\begin{itemize}
    \item Understand
    \item Know
    \item Appreciate
    \item Be familiar with
    \item Learn
\end{itemize}

\textbf{Instead of:}

\begin{quote}
Learners will understand competency frameworks.
\end{quote}

\textbf{Write:}

\begin{quote}
Learners will explain the key components of a competency framework with at least three examples.
\end{quote}

\section{Sample Outcomes for a CBET Module}

\textbf{Module: Occupational Standards and Competency Framework}

By the end of the module, learners will be able to:

\begin{enumerate}
    \item Define key terms related to occupational standards. (\textit{Remember})
    \item Explain the components of competency standards. (\textit{Understand})
    \item Apply stakeholder engagement principles to competency identification. (\textit{Apply})
    \item Analyze industry needs to determine required competencies. (\textit{Analyze})
    \item Evaluate the relevance of existing occupational standards. (\textit{Evaluate})
    \item Design a competency-based occupational standard for a selected occupation. (\textit{Create})
\end{enumerate}

\section{Key Takeaway}

To state measurable learning outcomes using Revised Bloom's Taxonomy:

\begin{itemize}
    \item Choose the appropriate cognitive level.
    \item Use observable action verbs.
    \item Clearly describe the expected performance.
    \item Include measurable criteria where possible.
    \item Align outcomes with assessment methods.
\end{itemize}

Well-written learning outcomes improve clarity, guide instruction, and ensure meaningful assessment in competency-based education and training (CBET).
